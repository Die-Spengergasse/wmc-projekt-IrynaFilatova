# Donau Rental Manager

## Projektbeschreibung

Donau Rental Manager ist eine Webanwendung zur Verwaltung von Bootsreservierungen.

Mitarbeiter können Reservierungen für verschiedene Boote erfassen, den Kundennamen eingeben, die Mietdauer festlegen und Buchungen speichern oder löschen.

## Funktionen

* Neue Reservierungen erstellen
* Automatische Preisberechnung
* Buchungen löschen
* Speicherung der Daten im Local Storage
* Anzeige aktueller Wetterdaten über eine Web API
* Navigation zwischen Reservierungen und Wetteransicht

## Verwendete Technologien

* HTML
* CSS
* JavaScript
* Local Storage
* Open-Meteo API
* async/await

## Projektstruktur

* index.html – Benutzeroberfläche
* styles.css – Design und Layout
* app.js – Anwendungslogik
